## Scope

Added the cross-block conformance suite in `tests/blocks/test_conformance.py`
(new), parametrized over every built-in in a real `BlockRegistry` snapshot:

- Metadata: non-empty name/category/description, `OutputKind`, API version
  1, built-in source/hash markers, and input names present in `params`.
- Defaults: every `ParamKind` has the right spec and a default inside its
  range/options; image inputs are required; optional masks default to None;
  seeds default to None or an int.
- Output and determinism: each block is called twice with synthetic 32x32
  image/second/mask inputs and its default parameters (seed 0 for `SEED`).
  The result type and shape are checked, and the two calls must be
  identical.
- Boundaries: each built-in module source is checked for forbidden imports
  (`io`, `ui`, `runner`, `canvas`), `print`, file I/O (`open`, `cv2.imread`,
  `cv2.imwrite`), Pillow, matplotlib, and non-`default_rng` global RNG.
- Segment: the source uses `np.bincount` and does not loop with
  `np.unique(segments)`.

## Deviations

- Workspace policy blocks `git switch`; committed directly on `main`.
- The boundary checks are static source assertions because the requirement
  is an architectural boundary, not a runtime behavior. They are
  deliberately narrow (imports, I/O, printing, global RNG) and do not
  inspect implementation details beyond the segment `np.bincount` rule.
- The conformance call uses the block's declared defaults; `SEED` is
  injected as 0 so stochastic blocks are exercised deterministically.
