## Scope

Added `src/pic_utils/pipeline/plan.py` implementing architecture §7.2:

- `build_plan(config, pipeline, snapshot, source_count)` for grid, random,
  and hybrid modes.
  - grid: cartesian product of axis values (the empty product is 1) for each
    source; `batch_size` ignored.
  - random: `batch_size` samples distributed round-robin across sources.
  - hybrid: `product(axes) × random_samples` per source.
- `sample_parameter` implements the distributions: IntRange aligned to
  `step`, FloatRange uniform or log and quantized to `step`, Choice, Bool,
  Color (`#rrggbb`), and Seed never sampled.
- Experiment seeds are `derive_seed(master_seed, "experiment", index)` and
  sampling uses a per-index `default_rng`, so plans are deterministic and
  independent of iteration order.
- The 10,000-experiment guard raises `ValidationError` carrying
  `run.too_many_experiments`.
- `estimate_run_bytes` / `disk_preflight` implement the 30 MB-per-result disk
  estimate and the 2× headroom warning threshold.

## Deviations

- Workspace policy blocks `git switch`; committed directly on `main`.
- `RunConfig.mode` is typed `str` in the model (not `Literal`) because the
  model file is owned by P3-01; `build_plan` raises `ValueError` for an
  unknown mode and `validate_run_config` counts it as zero experiments.
- An axis or sampled entry that does not resolve (unknown step/param) is
  skipped by the planner; validation reports it as `run.invalid_axis`, so the
  planner never raises on a config the UI is already blocking.
