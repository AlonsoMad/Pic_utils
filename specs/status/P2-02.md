## Scope

Implemented the reloadable block registry per architecture §5.4-§5.5 and
implementation-plan §8 (P2-02):

- `src/pic_utils/blocks/registry.py` (new): `BlockSnapshot` (immutable
  mapping + hash), `ReloadReport` (loaded/updated/removed/errors/duration),
  and `BlockRegistry(QObject)` with a `changed` signal.
  - Built-ins are discovered from `pic_utils.blocks.builtin` with
    `pkgutil.iter_modules`; `builtin/__init__.py` stays docstring-only.
  - User blocks are imported from a configured folder; each file is
    imported as `pic_utils_userblocks.<stem>` with the folder on
    `sys.path` so helper imports work.
  - Per-file last-good: an import/signature error keeps that file's
    previous definitions and records a `BlockLoadError`.
  - Duplicate names and built-in shadowing are rejected with an error.
  - The snapshot hash is sha256 over sorted built-in
    `(name, content_hash, api_version)` plus sorted
    `(relative_path, sha256)` for the user files (last-good hashes for
    files that currently fail to import).
  - `set_user_blocks_dir` swaps the folder and reloads.
- `src/pic_utils/blocks/userblocks.py` (new): file iteration, recursive
  hashing, module purge (including `__pycache__`, so same-size edits are
  not served from stale bytecode), module loading, and `BlockDef`
  collection with registry metadata.
- `tests/blocks/test_registry.py` (new): 15 tests covering built-in
  discovery, user load/execution, reload diffs, syntax-error last-good,
  duplicate/shadow rejection, helper-module reload, snapshot hash
  stability/change, snapshot immutability, the `changed` signal, unknown
  names, folder switching, bad signatures, and built-in opt-out.

## Deviations

- Workspace policy blocks `git switch`; committed directly on `main`.
- `BlockRegistry` is a `QObject` with a `changed = Signal(object)` per the
  architecture. The `QFileSystemWatcher` auto-reload is a UI concern and
  is left to the Lab shell phase; `reload()` is the manual entry point.
- The user-blocks folder is an explicit constructor argument (default
  `None` = no user blocks). The settings layer (P5-01) supplies the
  `QStandardPaths` default; the registry does not import Qt paths.
- `purge_user_modules` deletes `__pycache__` under the user folder. Without
  it, a same-size edit within the filesystem timestamp resolution is
  served from stale bytecode (caught by the helper-reload test).
- Duplicate names keep the first definition (built-ins first, then files
  in sorted path order) and record an error for each later definition.
- The snapshot hash uses the last-good file hash for a file that currently
  fails to import, so the hash describes the code a run would actually use.
