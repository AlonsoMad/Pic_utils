## Scope

Implemented the color and statistics utilities per architecture §4.3 and
§5.7, and implementation-plan §8 (P1-02):

- `src/pic_utils/core/color.py` (new): `parse_hex_color` (`#RRGGBB`,
  `RRGGBB`, `#RGB`), `to_hex_color`, `luminance` (Rec. 709, float32),
  `to_bgr`/`from_bgr` (the only OpenCV channel-order bridge).
- `src/pic_utils/core/stats.py` (new): `find_channel_percentiles` for 2-D
  grayscale or 3-D channel-last integer arrays. Uses a 256-bin histogram
  (one linear pass per channel); percentile 0 returns the channel minimum,
  matching `numpy.percentile(..., method="inverted_cdf")`.
- `tests/core/test_color.py` (new): hex parsing/round-trip, invalid input,
  Rec. 709 luminance, BGR swap/round-trip, shape/dtype rejection.
- `tests/core/test_stats.py` (new): comparison against
  `numpy.percentile(..., method="inverted_cdf")` for 0/1/10/50/90/95/99/100,
  grayscale, percentile-0 minimum, non-uint8 integer input, and invalid
  inputs.
