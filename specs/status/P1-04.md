## Scope

Added the §20.3 I/O edge-case tests in `tests/io/test_edge_cases.py` (new):

- Corrupt image and corrupt mask files raise `ImageLoadError`
  (`probe_image` included).
- An unwritable target directory raises `ExportError` and leaves no
  partial/temporary file (POSIX-only; skipped on Windows and when running
  as root).
- A missing destination directory raises `ExportError`.
- CMYK TIFF loads as RGB (white/black sanity values).
- Palette PNG loads as RGB (red/green palette entries).
- JPEG flattens alpha onto white: transparent red -> white, opaque blue
  -> blue, half-alpha green -> (127, 255, 127), transparent black ->
  white. Samples block centers to avoid JPEG chroma-subsampling bleed.
- An unsupported source format (BMP) raises `UnsupportedImageError`.
- `save_mask` rejects non-PNG destinations.

## Deviations

- Workspace policy blocks `git switch`; committed directly on `main`.
- The unwritable-target test is skipped on Windows (POSIX permissions)
  and as root (root bypasses directory permissions). The portable
  `os.replace` failure path is covered by
  `tests/io/test_io.py::test_atomic_save_failure_leaves_original_intact`.
- The JPEG alpha test samples 4x4 block centers because chroma
  subsampling bleeds across a 2x2 image's block boundaries.
