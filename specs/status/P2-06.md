## Scope

Implemented the segmentation block per architecture §5.7 and
implementation-plan §8 (P2-06):

- `src/pic_utils/blocks/builtin/segment.py` (new):
  - Converts RGB to Lab, optionally runs SLIC (`superpixel_count`) and
    computes superpixel means with `np.bincount` (one bincount per channel,
    no Python loop over superpixels), then clusters with
    `MiniBatchKMeans(random_state=seed)`.
  - Without superpixels, clusters the Lab pixels directly (MiniBatchKMeans).
  - Emits one `Layer` per cluster, cropped to the cluster's bounding box,
    with alpha 0 outside the cluster and the source alpha inside it.
  - `min_cluster_pixels` skips small clusters; if none remain the block
    raises instead of returning an empty layer list.
  - `modular_recolor` applies `(channel * offset) % modulus` with offsets
    from `np.random.default_rng(seed)`; `modulus` is guarded against zero.
  - Layer count is capped at 16.
- `tests/blocks/test_segment.py` (new): 8 tests covering layer counts,
  bounding-box crops, fixed-seed determinism on both paths, seeded modular
  recolor bounds, minimum-cluster filtering, the zero-modulus guard, and
  the 16-layer cap.

## Deviations

- Workspace policy blocks `git switch`; committed directly on `main`.
- When superpixels are enabled, KMeans clusters the **superpixel means**
  (at most `superpixel_count` samples) rather than every pixel. This is
  equivalent to the legacy mean-image clustering, much faster, and keeps
  the `np.bincount` requirement.
- `min_cluster_pixels` defaults to 0 (all non-empty clusters). If every
  cluster is filtered, the block raises `ValueError`; the executor records
  `block.raised` and the experiment fails rather than emitting an invalid
  empty `LAYERS` result.
- The source alpha is preserved inside each cluster (the cluster mask
  multiplies it); outside the cluster the layer alpha is 0.
- `n_init=3` is explicit for deterministic, bounded-cost KMeans runs.
