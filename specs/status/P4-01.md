## Scope

Implemented architecture §9.1-§9.3 run layout, manifest, curation, and trash:

- `src/pic_utils/runner/__init__.py`: package docstring only (importing
  `pic_utils.runner` must never pull in Qt; `service.py` is added by P4-05).
- `src/pic_utils/runner/manifest.py`: `RunStore` (folder tree, atomic
  `manifest.json`/`curation.json` writes, append-only flushed
  `results.jsonl`), `ResultRecord` (de/serialization), `RunData`,
  `new_run_id` (`YYYYMMDD-HHMMSS-<6 hex>`), `result_id`
  (`"{experiment:04d}:{layer:02d}"`), UTC manifest timestamps.
- `src/pic_utils/results/trash.py`: `SessionTrash` move/restore preserving
  run-relative layout, `new_session_id` (`YYYYMMDD-HHMMSS-<pid>`),
  `prepare_trash` (startup: create session dir, delete other sessions'),
  `cleanup_current` (clean exit). Run-relative paths from `results.jsonl`
  are validated at the boundary (absolute, `..`, and `\` rejected) because
  `os.replace` would otherwise move files outside the run's trash subtree.
- `src/pic_utils/results/store.py`: `list_runs` (newest first, ignores
  non-run directories), `load_run`, `discard_result`/`restore_result`
  (move first, then record — §9.3 ordering), `AcceptedIndex` for the canvas
  tray (refresh + incremental curation events).
- Tests: `tests/runner/test_manifest.py` (17), `tests/results/test_trash.py`
  (19), including torn-final-line tolerance, atomic-rewrite evidence, and
  trash path-traversal rejection.
