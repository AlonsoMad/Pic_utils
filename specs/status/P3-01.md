## Scope

Added `src/pic_utils/pipeline/__init__.py` and `pipeline/model.py` with the
architecture §6.1 value types and the architecture §7.1 planning inputs:

- `PipelineStep` (id, block, scalar `params`, `bypass`, `mask_bindings`) and
  `Pipeline` (ordered tuple of steps), both frozen.
- Lossless plain-dict serialization `{"steps": [...]}` via `to_dict()` /
  `from_dict()`; step ids are stored verbatim and never regenerated.
  Malformed payloads raise `ValueError` with the step index.
- `SweepAxis`, `RunConfig`, `ExperimentSpec` (shared by the planner and the
  executor).
- `derive_seed(master, *parts)`, the blake2b 31-bit derivation from §7.2,
  pinned by tests so the algorithm cannot drift silently.

## Deviations

- Workspace policy blocks `git switch`; committed directly on `main`.
- `derive_seed` uses the exact §7.2 byte stream (no separators between
  parts), so `derive_seed(0, "a", "b") == derive_seed(0, "ab")`. This is a
  property of the specified algorithm; the test suite does not assert
  otherwise.
- `derive_seed` lives in `pipeline/model.py` because it is the shared
  primitive for both the executor (step seeds) and the planner (experiment
  seeds), and no separate file is in this task's ownership list.
