## Scope

Implemented the worker protocol and shared-memory image transport
(architecture §8.2-§8.3, §8.8):

- `src/pic_utils/runner/protocol.py`: `ImageHandle` (RGB block + optional
  separate alpha block, `nbytes` for memory accounting), `ExperimentTask`
  (with `run_id` so the worker can build run-relative paths),
  `ResultFile`, `ExperimentOutcome` (status `ok`/`failed`/`cancelled` plus
  the stable error code — `block.raised`, `block.invalid_output`, …), and
  the event-queue records `WorkerReady` / `ExperimentStarted` / `WorkerLog`.
  All picklable, Qt-free.
- `src/pic_utils/runner/shm.py`: `SharedImageStore` (put/attach/release/
  close; names `picutils_{run_id}_{index}`; parent owns the blocks and
  unlinks on release/close; a failed `put` releases its partial blocks), and
  `attach_image` (worker side: attach by name, copy into private arrays,
  close, never unlink). Creation/attach failures raise
  `RunError("shm.unavailable")` — no silent fallback (§8.8).
- Tests: `tests/runner/test_shm.py` (12), including round-trips for RGB and
  alpha, unique names, private-copy semantics, a POSIX `/dev/shm` leak test,
  a partial-`put` failure-leak test, and a spawn-process attach test.

## Deviations

- Workspace policy blocks `git switch`; committed directly on `main`
  (matches P1-P4).
- `ExperimentTask` carries `run_id` in addition to `run_dir` (additive; the
  §8.3 sketch omits it, but the worker needs it to build run-relative result
  paths without guessing the results root).
- Outcome status includes `"cancelled"` (§8.4 force stop marks in-flight
  experiments cancelled; the §8.3 sketch lists only `ok`/`failed`).
