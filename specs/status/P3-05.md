## Scope

Added `tests/pipeline/test_contract.py` covering the invariants that span the
pipeline package:

- Architectural boundary: a clean subprocess imports every pipeline module
  and asserts no `PySide6`/`pic_utils.io` module is loaded; an AST scan of
  every `pipeline/*.py` rejects runtime imports of Qt, `pic_utils.io`, and
  stdlib `io` (imports inside `if TYPE_CHECKING:` are ignored).
- Serialization: a pipeline round-trips through `to_dict`/`from_dict` and
  executes identically.
- Validation ↔ execution: a pipeline that validates without errors executes
  for every planned experiment and yields one correctly sized layer.
- Validation ↔ planner: both report/raise `run.too_many_experiments` at the
  same limit.
- Seed reproducibility: the same plan executed twice produces identical
  output, and distinct experiment indices produce distinct derived seeds.
- Random plans: sampled values flow through the executor end to end.

  clean subprocess (catches transitive imports) and a static AST scan (names
  the offending module). The AST scan ignores `TYPE_CHECKING` imports, which
  is how the validator references `BlockSnapshot` without importing Qt.
