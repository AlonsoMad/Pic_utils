## Scope

Created the package skeleton and tooling per architecture §21.2 and stack §4:

- `pyproject.toml` (new): project metadata (`pic-utils` 0.1.0, `requires-python = ">=3.12,<3.13"`), the seven runtime deps from §21.1, `dev` extra, hatchling backend with wheel packages `["src/pic_utils"]`, ruff (line-length 100, target py312, lint select E/F/I/UP/B/SIM/RUF), mypy (python_version 3.12), pytest config (testpaths, addopts, slow/gui markers, `pythonpath = ["src"]`), and the `pic-utils` entry point.
- `src/pic_utils/__init__.py` (new): package docstring, `__version__ = "0.1.0"`, `__all__ = ["__version__"]` only; no feature code, no heavy imports.
- `tests/fixtures.py` (new): deterministic synthetic image helpers (`rgb_gradient`, `checkerboard`, `mask_gradient`, `rgba_gradient`), numpy arrays with fixed shapes/dtypes, no randomness, default 8x8, documented.
- `tests/conftest.py` (new): exposes the synthetic helpers as pytest fixtures (8x8 default).
- `tests/test_smoke.py` (new): real behavior tests — package metadata matches `importlib.metadata.version("pic-utils")` and `pic_utils.__version__`; fixtures deterministic with expected shape/dtype.
- `.github/workflows/ci.yml` (new): GitHub Actions, matrix `ubuntu-latest` + `windows-latest`, Python 3.12, `QT_QPA_PLATFORM=offscreen`, steps: checkout, `astral-sh/setup-uv@v5` (python-version 3.12, enable-cache), `uv sync --extra dev`, the four gates, on push and pull_request, `fail-fast: false`.
- `.gitignore` (edit): kept existing content; verified entries for `.venv/`, `.pytest_cache/`, `.ruff_cache/`, `.mypy_cache/`, `dist/`, `build/`, `*.egg-info/` are present; `uv.lock` not ignored.
- `README.md` (edit): added a concise Development section only (prerequisites Python 3.12 + uv, `uv sync --extra dev`, the four gates, src/tests layout); existing content unchanged.
- `uv.lock` (new): generated by `uv sync --extra dev`, committed.
