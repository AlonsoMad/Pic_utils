## Scope

Implemented the canonical image value types per architecture §3 and
implementation-plan §8 (P1-01):

- `src/pic_utils/core/image.py` (new): `Image` (frozen, slots, `eq=False`)
  with `(H, W, 3)` uint8 RGB plus optional `(H, W)` uint8 alpha; properties
  `width`, `height`, `size`, `nbytes`; `from_rgb`, `from_rgba`, `to_rgba`,
  `with_alpha`, `copy`, `resized`, `to_proxy`. Construction validates
  dtype/shape/alpha geometry, copies non-C-contiguous input, and marks both
  planes read-only. No pixel-value scans.
- `Mask` (frozen, slots): `(H, W)` uint8 data plus `soft`; validates
  dtype/shape/contiguity and freezes the plane. Binary-value validation is
  deliberately left to the executor's output validator (§5.6).
- `Layer` (frozen, slots): `image`, optional `mask`, `name`; rejects a mask
  whose shape differs from the image.
- `BlendMode` (`StrEnum`): the six FR-CAN-04 modes.
- `tests/core/test_image.py` (new): 28 behavior tests covering geometry,
  dtype/shape rejection, non-contiguous normalization, read-only
  enforcement, alpha validation/splitting, `to_rgba` opaque fill, copy
  independence, resize/proxy aspect and alpha, mask/layer invariants, and
  the blend-mode values.
