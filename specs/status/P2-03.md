## Scope

Implemented the two channel blocks per architecture §5.7 and
implementation-plan §8 (P2-03):

- `src/pic_utils/blocks/builtin/channels.py` (new):
  - `channel_permute` (`IMAGE`): reorders the input channels by the
    `order` permutation (`rgb`…`bgr`), then optionally inverts the selected
    output channels. Alpha is preserved.
  - `permutation_grid` (`LAYERS`): `channel_order` emits the six orders
    (plus the original first when `include_original=True`); `invert` emits
    the eight per-channel inversion combinations. Layer count is 6-8.
- `src/pic_utils/blocks/builtin/__init__.py` (new): docstring-only package
  marker so the registry's `pkgutil.iter_modules` discovery can find the
  built-in submodules.
- `tests/blocks/test_channels.py` (new): 10 tests covering identity,
  channel swaps, inversion order, invalid orders, layer counts and names,
  alpha preservation, determinism, and invalid modes.

## Deviations

- Workspace policy blocks `git switch`; committed directly on `main`.
- The §5.7 table says `permutation_grid` emits 6-9 layers, while the
  implementation note says "at most 8". Implemented at most 8:
  `channel_order` = 6 (7 with `include_original`), `invert` = 8 (the
  no-inversion combination is the original, so `include_original` has no
  effect there).
- `blocks/builtin/__init__.py` is created here as a package marker; it
  stays docstring-only per the discovery rule (P2-02 owns the registry
  that consumes it).
